Na premissa das aplicações desenvolvidas mencionadas no capítulo 3.1, percebe-se como apesar de ambos se desenvolverem em cenários diferentes, um enquanto plataforma web (Notion) e outro enquanto uma plataforma no desktop (obsidian), ambos conseguem cobrir diferentes áreas através de diferentes métodos, seja através de ferramentas já dispostas pelo sistema ou por abordagens criadas pelo usuário ou por uma comunidade. Deste modo, o presente projeto pretende trabalhar na premissa da criação de um sistema que seja capaz de funcionar enquanto um website e também uma aplicação desktop. No entanto, a primeira meta se consiste em montar uma plataforma *web*. 

A seguir, haverão diversos protótipos desenvolvido na plataforma de criação de interfaces digitais *Figma* para melhor visualização do conceito do sistema a ser desenvolvido.

Figura 13 - Tela de Bem vindo![[Tela 1.png]]

A tela de bem vindo seria o primeiro passo do usuário ao se deparar com o sistema, nela há a disposição das funções de *Login* e a função de cadastro através do botão "Comece Agora". Crê-se que esta seja uma boa forma de se apresentar ao usuário pela premissa de dispor todas informações necessárias a poucos cliques de distância.

Figura 14 - Protótipo da tela de seleção![[Tela de Selecao.png]]

Para que o usuário seja capaz de registrar no sistema e começar a cultivar suas anotações, ele seria redirecionado a uma tela que oferecia tanto a opção de criar uma conta quanto a opção de já fazer o login caso já a tenha. 

Figura 15 - Protótipo Tela de Cadastro
![[Tela de Cadastro 1.png]]

E para que o sistema fosse capaz de registrar seu usuário, poucas informações seriam requisitadas, para servir o propósito de *login* na posterioridade, seria exigido apenas o nome de usuário e seu e-mail para registrar um nome sob a conta, a senha seria um modo de garantir maior segurança ao usuário. Nesta tela também há a opção caso o usuário já tenha uma conta, exibida através das letras miúdas "Já tem uma conta?".

Figura 16 - Protótipo de Tela Inicial![[Tela da opção 1.png]]

A partir do instante em que o usuário tem uma conta e faz acesso a ela, ele seria redirecionado para a sua página essencial, ela exibiria todas os campos de anotações criadas pelo próprio, facilitando assim, navegar entre telas e diferentes áreas. É possível ver um botão para registrar este espaço, que pediria nada mais do que um nome para o grupo e uma imagem para tal conjunto. 

Figura 17 - Protótipo de área de trabalho ![[Tela da opção 2.png]]

A imagem acima representa o que seria devidamente o cerne do sistema, carecendo apenas da visualização de uma meta vigente que seria a implementação de tabelas e quadros Kanban a livre vontade de seu usuário. Além da customização do texto inserido, como é possível ver pela sequência de "Planos" na imagem, o texto se difere por tomar uma coloração diferente de preto, isto se deve a sua propriedade de link externo adquirida, algo que seu usuário decide fazer ou não. Para a desenvoltura completa do fluxo de ideias, o sistema deve permitir que o usuário adentre esta aba de planos, e dentro da aba de planos, seja capaz de criar ainda mais links externos, criando uma ligação infinita entre páginas.

Para o sistema proposto, resta-se o desenvolvimento de telas que contemplem a proposta visualização entre as anotações, uma aba que permite a visualização constante de tarefas criadas pelo usuário e também a tela de filtragem, pois o sistema se propõe e estabelecer um sistema de etiquetas para cada nota, para que assim, na posterioridade, ao desejo de seu usuário, utilizando a ferramenta de pesquisa, ele poderia encontrar apenas as anotações que contém a etiqueta de "Trabalho".
