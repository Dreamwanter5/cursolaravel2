### Possível citação com o propósito de polir o texto no trecho de ferramentas. 


(BALLERINI, 2021). Outrossim, Ballerini (2021, p. 1), descreve o papel que cada uma desempenha e faz uma comparação um tanto
quanto inusitada:

1. HTML: linguagem de marcação utilizada para estruturar os elementos da
página, como parágrafos, links, títulos, tabelas, imagens e até vídeos. 2. CSS: linguagem de estilos utilizada para definir cores, fontes, tamanhos, posicionamento e qualquer outro valor estético para os elementos da página. 3. Javascript: linguagem de programação utilizada para deixar a página com
mais movimento, podendo atualizar elementos dinamicamente e lidar
melhor com dados enviados e recebidos na página [pode-se utilizar o corpo
humano como exemplo]. O HTML é o esqueleto, composto dos ossos que o
sustenta. O CSS é a pele, cabelo e roupas, criando o visual que realmente
enxergamos quando olhamos para alguma pessoa. E por fim, o Javascript é
o músculo, que dá movimento ao corpo. O Sistema Gerenciador de Banco de Dados
