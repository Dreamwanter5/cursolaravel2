### Princípios de redes: 

***OSI (Open System Interconnection) Aplicação***
> O modelo Open Systems Interconnection (OSI) é uma estrutura conceitual que divide as funções de comunicação de rede em sete camadas

- Rede
- Enlace 
	- ``Camada MAC - Surge dado o grau de importância da camada de Enlace
- Física
- Transporte
- Apresentação
- Aplicação

- ***TCP/ IP ( Transmission control protocol)

Este conteúdo serve para a saída de dados, de um servidor até um cliente. 
Curiosamente, no protocolo TCP, dados não se perdem, pois acontece o processo de retransmissão de dados, usado para garantir a entrega de dados corretamente. Ex: E-mails, sites, vídeos, etc. (Política de vinho)
> TCP/IP é um conjunto de protocolos que possibilita a comunicação entre computadores e servidores, formando a Internet.

----
**UDP** - é semelhante ao TCP, porém, a entrega de dados funciona de modo diferente, isso porque este processo prioriza entrega de dados sobre a qualidade (Política de leite). Ex: Serviços menos necessários, streaming, youtube, etc.

----
*Elementos do **TCP***

- Transporte
- Rede
- Host-rede
- Inter-Rede (Internet)

Anotações: Usado para a transferência de pacotes de imagem, esta etapa ainda é suscetível a falhas, justamente por comunicar várias imagens através apenas um pacote.

***COOKIES:*** Instrumentais para manter o seu dispositivo *Logado* em sites, ele é o agente responsável pelo funcionamento de Redes, o mesmo é instalado dentro do seu computador, em cliques, envia informação para o servidor, coloca o usuário em sua respectiva conta. Assim, se faz a interação entre um dispositivo desconectado do servidor com o próprio servidor.
